# Complex_systems_assignment 2; Rising variance: a leading indicator of ecological transition.

## Description
This repository contains a notebook with which part of the methodology from an article of Carpenter & Brock (2006) can be replicated, with as goal to replicate figure 2 from the paper. It contains the notebook, a requirements file and a guide on how to run to run the notebook.

## Dependencies
- python 3.11+
- requirements.txt
